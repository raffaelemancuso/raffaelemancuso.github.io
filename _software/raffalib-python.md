This is my Python library with miscellaneous utilities I frequently use.

Its main purpose is to provide [STATA](http://www.stata.com)-like logging capabilities (i.e., a [tidylog](https://github.com/elbersb/tidylog) for Python) and Word export capabilities for [pandas](https://pandas.pydata.org/) and [polars](https://pola.rs/). But it also has other data analysis capabilities like frequency tables and cross tables. It is featured on [awesome-polars](https://github.com/ddotta/awesome-polars).
